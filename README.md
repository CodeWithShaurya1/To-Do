# 📝 To-Do List

A simple and user-friendly To-Do List web application built using HTML, CSS, and JavaScript.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit tasks by double-clicking
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- ⌨️ Add tasks using the Enter key
- 📱 Simple and responsive interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
